## 🎯 Purpose

This documentation follows a **"living documentation"** philosophy:

- **Always Current**: Updated with every PR to reflect the actual state of the code
- **Agent-Friendly**: Written with AI agents in mind for maximum clarity and context
- **Comprehensive**: Covers both high-level concepts and implementation details
- **Actionable**: Provides clear guidance for making changes safely

## 🔄 Maintenance

**For every PR, please update relevant documentation:**

1. **System changes** → Update `SYSTEM_ARCHITECTURE.md`
2. **New modules** → Update `CODE_ORGANIZATION.md`
3. **Database changes** → Update `DATABASE_SCHEMA.md`
4. **API changes** → Update `API_DOCUMENTATION.md`
5. **New tests** → Update `TESTING_STRATEGY.md`

This ensures the next contributor (human or AI) has accurate, up-to-date context.
